# OVERDRIVE 1.0.1 artwork

Game artwork was made for this project using the built-in image-generation tool. The project bundles optimized WebP copies, so it does not contact an image service at runtime.

- `public/assets/worlds.webp`: six realistic fantasy environment paintings in a two-column, three-row atlas. The five regions use the first five panels; an alpine variant uses the sixth. The code crops and shades the paintings while drawing actual platforms separately.
- `public/assets/fighters.webp`: five original transparent full-body character cutouts. They are used in selection portraits and procedurally deformed in gameplay. Weapon art and effects are drawn separately in code.

## 1.0.1: articulated parts and new equipment

The built-in image-generation tool produced two additional locally bundled assets. The original environment paintings remain unchanged.

- `public/assets/rig.webp`: forty isolated body parts in eight columns and five character rows, preserving the five original costume identities. Alpha components were located while packaging and their rectangles are bundled in the renderer; it attaches and rotates those textures around continuous joints without reading image pixels at runtime. The original character art was supplied as reference.
- `public/assets/weapons.webp`: fifteen detailed equipment icons, three columns by five rows. A follow-up edit removed background haze while preserving the layout. Runtime crops and rotations attach them to the hands. The vector designs are fallback only.
